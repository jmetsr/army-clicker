Verify Spending Doesn't Exceed Balance
=======================================

GOAL: Check that players don't spend more coins than they have.

TASKS:

1. Track coin balance through log
   Starting from 0 (or logged start):
   - Add income events
   - Subtract purchase costs
   - Balance should never go negative

2. Create SpendingVerifier class
   - Replay transactions in order
   - Calculate correct costs (with inflation)
   - Flag if balance goes negative

3. Handle building cost inflation
   - Base costs from game constants
   - Inflation: cost × 1.04^(buildings_owned)
   - Need to track purchase count per building type

4. Tolerance
   - Allow small negative (rounding)
   - Flag significant overspend (buying without funds)

5. Output
   - List of transactions where balance went negative
   - How much they overspent by

DEPENDENCIES:
- Task 07a (parsed log)
- Task 07c-ordinal-number (for big number math)

ESTIMATE: 2 hours

NOTES:
- Simpler than income verification
- Catches: money editing, buy-without-paying hacks
- May need game constants (base costs) synced to PHP
