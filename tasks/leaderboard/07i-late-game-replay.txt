DETERMINATION: Full PHP late-game replay is NOT feasible because:
1. JS OrdinalNumber supports NESTED heights (height can be another OrdinalNumber)
   - Example: {arrows:2, height:{arrows:1, height:50}} = 10↑↑(10^50)
   - PHP flattens this, losing precision
2. JS exp10() method not implemented in PHP (critical for auto-upgrader cascades)
3. JS comparison uses complex _flatten() method for nested structures
4. Floating-point differences accumulate over millions of operations
5. After many operations, JS and PHP results diverge significantly

APPROACH: Trust early/middle validation + generous sanity checks for late game.
Players who cheat in late game would need to pass early/middle validation first,
which should catch most cheaters. Late game sanity checks focus on:
- Magic balance (can't spend more than earned)
- Unlock sequences (ruby requires emerald requires sapphire)
- Arrow jumps calibrated to auto-upgrader tier count
- Auto-upgrader count vs magic spent (each costs 10 magic)
